# Skill Usage Rules

## frontend-design + web-design-guidelines
Use BOTH together whenever the task involves:
- Creating or editing any UI component, page, or layout
- Landing pages, dashboards, onboarding flows
- Animations, transitions, or motion design
- Design system decisions (colors, typography, spacing)
- Responsive design or mobile-first considerations
- Any time a `.tsx` or `.css` file is created or significantly modified

## brainstorming
Use whenever the task involves:
- Exploring product decisions or feature direction
- Discussing growth, monetization, or positioning strategy
- Evaluating technical architecture tradeoffs
- Ideating solutions before committing to implementation
- Any open-ended "what should we do about X" discussion

## copywriting
Use whenever the task involves:
- Writing or editing landing page copy
- CTAs, headlines, value propositions
- Email sequences or WhatsApp onboarding messages
- Marketing strategy, acquisition channels, or messaging
- Any user-facing text that needs to convert or retain
